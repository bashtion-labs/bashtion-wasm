# Modules kept in the guest (plus their modules.dep closure); everything else
# in /lib/modules is pruned at build time. A name missing as both module and
# builtin fails the build.
#
# A `?` prefix means "keep it if this kernel has it". Netfilter in particular
# keeps folding small expression modules into nf_tables itself (nft_counter
# went that way), and a name that is now part of the core is neither a module
# nor listed in modules.builtin. The hard requirements are asserted separately
# in the Dockerfile, so optional here does not mean unchecked.

# firewalling.
#
# Ubuntu's iptables is iptables-nft: every `-m conntrack`, `-p tcp`, `-m limit`
# and friend in ufw's default ruleset is instantiated through nft_compat, the
# xtables-over-nftables shim. Without it `ufw enable` fails ufw-init with
# "Extension <name> revision 0 not supported, missing kernel module?" for each
# one, and leaves the kernel default-deny with no rules loaded while
# `ufw status` reports the firewall active - loopback included, which is how a
# local curl ends up hanging for 317 s. Keep the shim and the extensions ufw's
# before/after/user rules actually reference, for both address families.
